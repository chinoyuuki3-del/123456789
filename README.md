# Troll Engine GitHub Cloud

Troll Engine HTMLから読み取る公開クラウドデータです。

## 保存する情報
- メンテナンス状態
- 機能ON/OFF
- テストチャンネル
- 公開称号・実績
- プラン名と容量上限
- 公開を許可したユーザーID・表示名

## 保存しない情報
パスワード、メールアドレス、住所、位置情報、個人チャット、非公開ファイル、GitHubトークン、オーナーキーは保存しません。

管理更新は `chinoyuuki3-del` のGitHub操作だけを受け付け、Troll Engine HTMLには秘密情報を埋め込みません。
